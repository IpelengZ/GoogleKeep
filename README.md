How It Works

Creating a Note:
Click on the note input area to open the full note form. Enter a title and/or note text and then close or submit the form. 
The note is added to the beginning of the notes list.

Saving Notes:
Notes are stored in the browser's localStorage. This means notes remain available when the page is refreshed.

Archiving Notes:
Each note has an archive button. Clicking the archive button changes the note's archived status.
Archived notes are removed from the main notes display.
